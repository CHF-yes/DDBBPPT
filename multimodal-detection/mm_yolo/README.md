### v4 相对 v3 的改动（把"如何做"写成可实现的规格）

| # | 改动 | 落点 |
|---|---|---|

### v3 相对 v2 的定位修正（重要）

| # | 改动 | 原因 |
|---|---|---|
| 1 | **删除"融合只值 1~2 分 / 只负责别掉底"的定位** | 该数字来自**人为布景**的 VDT（RGB 主导、depth 近乎无信息）。同文档既写"VDT 不可外推"又用它给融合定价，自相矛盾 |
| 2 | **融合升为一等目标**，与分辨率/规模并列；架构必须能表达**强跨模态交互** | 官方强调三模态 + 实地场景（黑夜/拥挤/恶劣天气）→ IR/Depth 的潜力被释放，**融合很可能是主要分差来源** |
| 3 | **辅助模态通路给足容量**，明确否决"小容量随机流" | 旧方案 32/48/64 通道随机初始化 = 结构性压制辅助模态，在官方数据上直接丢分 |
| 4 | **互补性测量改为"推理期模态屏蔽剖面"**（D1） | 同一个三模态模型分别屏蔽 IR/Depth/RGB，按条件切片测掉点 → **零额外训练**即得"哪个模态在哪种条件下值多少分" |
| 5 | **撤退门 → 投资分配门**：按切片掉点决定容量与工程量，**不再预设融合低价值** | 定价权交还官方数据实测 |
| 6 | **优化目标改为"困难切片优先"**（夜间/拥挤/小目标切片领先），而非平均分 | 隐藏测试集难度递增，且这些切片最容易拉开差距 |
| 7 | **对齐/深度表示与主干并行推进**（不再"以 E6 为门"） | depth 既然可能承载关键信息，对齐就是前置投资而非可选项 |

### 2026-09-17 持久 Register 融合实现

- 保留三模态分支和 L2/L3 局部跨模态注意力，不改成六通道单主干；
- 融合输出改为 RGB 锚定的小非零残差，纯 RGB 样本严格恒等；
- Depth 的同一受限偏移网格同时用于主体加权、attention K/V、有效掩码和质量图；
- 有幻影的 Depth 默认仅进入 P4/P5，可用 `--depth-scales all` 做反证消融；
- `PersistentRegisterBus` 的同一每图状态依次执行 R0→R1→R2→R3，并在各尺度双向读写；
- 当前 `--late-bus` 是旧的一次性 FiLM，仅作对照，禁止与持久 register 同时打开；
- Linux/服务器通过 `--weights /abs/path/yolo11s.pt --device cuda:0` 显式指定环境，
  eval/submit 跨机器加载时可用 `--base-weights` 覆盖 checkpoint 里的本地权重路径。

### B2：在保留三模态融合的前提下改造数据表示与训练配方

- Depth 输入改为 4ch：每图相对深度、毫米/20m 绝对深度、有效掩码、米制可用标志。仅对 uint16 毫米图使用绝对距离；uint8/JPG 不伪造米制信息。
- RGB 真低照（压暗，gamma>1）、IR 轻噪声、Depth 小块失效、Depth 错位 ±5px、15% 三模态同步目标感知裁剪。

## 2. 设计原则（修订）

| # | 原则 | 依据 |
|---|---|---|
| P1 | **融合承重靠"训练配方 + 架构"双管**：modality dropout 是核心，架构保证不被关掉 | 实测旧配置 `modal_dropout=0.0` → γ 收敛到 0.036–0.080、置零通道输出只变 **0.03%** |
| P2 | **RGB 稳定锚点 + 辅助模态自由加成**：IR/Depth 经门控、局部注意力与 register 真正参与，但不强制三路等权 | 保住 COCO 预训练主路，避免小数据上随机融合在第 0 步破坏特征分布 |
| P3 | **不从零训**：共享 stem + 跨模态复制初始化；只随机初始化小模块 | 实测辅助流随机初始化的小容量支路 → 关 depth 仅 −0.013 |
| P4 | **容量纪律 + 规模是一阶变量**：当前全部多模态新增参数约 1.08M；但 s/m 必须 A/B（不能因本机 6GB 就锁死 s） | 租卡 + COCO 初始化下 m 常直接赢，且比堆叠融合模块稳 |
| P5 | 对齐显式、逐图、鲁棒；depth 用相对深度 + 可靠性掩码；融合在**区域级** | 实测 −21px@1920（IQR −27..−16.5，8/17 可信）；残影使像素级对齐不可达 |
| P6 | 特征空间对齐**默认靠架构（共享/适配器）**，损失只在 E2 测到塌缩时才加 | 2000 张下每个 λ 都是失败模式 |
| P7 | **总线是带 kill 条件的期权**，不是地基 | 浅层单块 ≈ 高级 SE；文献现象来自深残差流 |
| P8 | 判定只认 Test 赛题口径；条件分位切片取**最坏值**；≥2 种子 | 实测 val 配对 +0.025 收敛后归零、Test 仅 +0.0046；单 run 噪声 ±0.005 |
| P9 | **一阶变量优先于结构变量**：分辨率/切片、模型规模、TTA 先做且先锁 | 评审结论 + 实测（融合通路影响力只有 0.03% ≠ 融合没价值，而是旧架构把它饿死了） |
| P10 | **融合收益的定价权归官方数据实测**：禁止用 VDT/人为布景数据给融合估值 | v3 修正；VDT 是室内桌面、RGB 主导，热力/深度潜力被压低 |
| P11 | **困难切片优先**：优化与选型以"夜间/拥挤/小目标切片领先"为目标，平均分只作参考 | 隐藏测试集难度递增，且难点切片是分差所在 |

## 3. 架构规格（修订）

```
RGB(3) / IR(1) / Depth(2)  → Stage A 对齐与表示 → Stage B 编码器 → Stage C 融合
                                                                    → Stage D 官方 neck（权重继承）→ Stage E Detect
```

### Stage A｜对齐与表示（v4：三段式规格）

**A1 估计（D0 一次算完，缓存；绝不在 dataloader 重算）**

1. 统一到**边缘域**：RGB 取亮度梯度幅值；depth 先去洞（小核中值/最近邻填充）再取梯度幅值；都降到工作分辨率（≈480px 宽）搜索。
2. 搜索空间：`(dx,dy)` 粗到细（步长 4→2→1 + 峰顶抛物线插值到亚像素）；若加 `scale∈[0.98,1.02]`、`θ∈[−1°,1°]` 后相关明显提升，则保留这两维。
3. **抗残影相似度**：梯度幅值的归一化互相关（NCC）或互信息（depth 若为视差则 MI 更稳）；对贡献像素 **trim 5–10%**，避免残影/补洞造成假峰。
4. **置信度 = 峰锐度**（主峰/次峰比、峰宽、支撑像素数）；**低于阈值向全局估计收缩**（经验贝叶斯）：`θ = w·θ_img + (1−w)·θ_global`，`w = f(置信度)`。→ 这就是"既不写死固定偏移，也不信噪声估计"。
5. **估计器自检（上线前必过）**：对已对齐样本人为施加已知偏移 → 能否复原到亚像素；再人为错位 → 退化是否单调。
6. 三对组合都测（RGB-IR / IR-D / RGB-D），确认 depth 对齐的对象到底是 RGB 还是 IR。

**A2 补偿（warp + 掩码）**

7. 参数模型双线性 warp；**有效性掩码一起 warp**（无效区保持无效，不许插值成假深度）。
8. **可靠性掩码**三来源合并：① 无效值；② 残影判据（depth 有强边但 RGB 无支撑边 且 局部方差高）；③ 分块残差位移过大处。
9. 增强加 **±10–20px 随机错位**（让网络对残余误差鲁棒，比追亚像素便宜）。

**A3 表示（非几何对齐，最容易漏）**

10. depth：相对深度（每图分位归一，抗未知单调预处理）+ 可选低频通道 + 可选法线。
11. IR：局部对比度/分位归一（否则绝对亮度漂移是无意义偏移）；**通道适配** 1×1（IR 1→3、Depth 2→3）以共享 stem。
12. 几何一致性：三模态同一仿射矩阵（沿用现有实现与断言）。

**A4 对齐的验收判据（v4 修正）**

13. **不看相关系数，看 §5.5 模态屏蔽剖面**：depth 从"屏蔽掉不掉分"变成"屏蔽掉显著掉分"，才算对齐真正生效；与主干并行推进，不作为前置门。

### Stage B｜编码器（**共享度三档 A/B，不写死**）

| 档 | 结构 | 说明 |
|---|---|---|
| (a) 完全分开 | 每模态独立 P3/P4/P5 后段（均用 COCO 权重复制初始化） | 容量最大；2000 张下有风险，但**不是**用"小容量随机流"替代 |
| (b) 共享 + 逐模态低秩适配器 | 共享主干 + FiLM/LoRA 适配（适配器从零初始化但秩低、参数少） | 小数据常最优，A/B 判断 |
| (c) 共享 + 逐模态 BN | 共享全部权重，只分开 BN 统计 | 成本近零，抹掉模态统计偏移 |

- **明确否决**："辅助模态 = 32/48/64 通道随机初始化小流"（旧方案的做法）——那等于在架构上压制辅助模态，官方数据上会直接丢分。
- 共享 stem 用 COCO 权重；档 (a) 的专用部分从共享权重**复制初始化**；档 (b)/(c) 直接共享。
- 逐模态 BN 保留（成本近零）。
- **容量与工程投入按 D1 的模态屏蔽剖面分配**（见 §5.5、§8）。

### Stage C｜融合（v4：四档阶梯，按"困难切片增益/参数增量"定档）

**C0 阶梯（从便宜到强，逐档加，每档都测 §5.5 剖面 + 困难切片）**

| 档 | 机制 | 能表达什么 | 参数效率 |
|---|---|---|---|
| **L0** | 逐像素门控加权和 | 只能"这里更信谁" | 高，但表达力最弱（**基线，必须能被打败**） |
| **L1** | L0 + 模态内 3×3 DWConv 上下文 | 加区域上下文 | 很高 |
| **L2** | **窗口化跨模态注意力**（RGB 为 query，IR/Depth 为 K/V，k=3~5） | 邻域内找最佳对应 → 容忍残余错位、局部互补 | **最高（性价比之王）** |
| **L3** | **L2 + 可变形小偏移**（±3px，初始化为 0） | 遮挡/形变/残余错位下的对应（学习式残差对齐） | 高 |
| **L4** | 同一组 latent register 贯穿 P3→P4→P5 | 跨尺度保存被空间压缩丢掉的三模态上下文，并双向读写 | 中（**须先赢过无 register 基线**） |

**C1 单尺度融合块规格（伪代码）**

```python
F = [F_rgb, F_ir, F_dep]                    # 已投影到 C 通道
L = [DWConv3x3(Fm) for Fm in F]             # 模态内局部上下文

# (a) 逐区域模态权重 α
desc  = [cat(GAP(Lm), GMP(Lm), DWConv3x3(Lm)) for Lm in L]
alpha = softmax(MLP(cat(desc)) / tau)       # (B,3,H,W)，Σ=1，空间可变

# (b) 局部跨模态交互（L2/L3 的核心；L3 才有 off）
q   = proj_q(L_rgb)                                        # 瓶颈投影 C'=C/4
off = conv(L_rgb) → (B, 2·G·k·k, H, W)，Δ ∈ [−3,3]           # L3：可变形采样
kv  = sample(L_ir, L_dep, off)                              # 邻域/偏移处取特征
I   = proj_o( softmax(q·kv/√C') @ kv )                       # 窗口内注意力

# (c) 融合 + 强制调制（承重，不可绕过）
F_out = BN( Σ_m alpha_m·(1+γ_m)⊙L_m  +  β·I )                # γ 有下限，初始化即通电
```

**C2 通用约束（四档都适用）**

1. **交互不能只有逐像素门控**：至少 L2 起步（真实场景的遮挡/极端光照下 L0 会明显吃亏），但**是否升到 L2/L3 由 E8 判定**（见 §6）。
2. **depth 喂到哪一层 = A/B 变量，默认只给 P4/P5**（当前 depth 有轻微幻影）；用 `--depth-scales all` 做三尺度反证。
3. **输出用 BN，不要用 LN**：预训练 neck 的 BN running stats 在 COCO 分布上估得，LN 会改分布 → neck 带过期统计跑。坚持非 BN 归一则必须做 **BN 重校准**（融合在环、几百 iter、高 momentum）。
4. **可靠性掩码作注意力偏置**；夜间另加 RGB 局部梯度能量（清晰度）作为门控特征。
5. **权重共享迭代 2 次**（深度翻倍、参数不增）；**监控迭代后特征范数比 ≤1.5**。
6. **参数预算**：瓶颈投影 + k=3 局部窗口保持轻量；当前持久 register 约 **0.379M**，全部多模态新增参数约 **1.08M**。
7. **占比（v4 结论）**：**局部交互占 ≈70–80%，全局仲裁（总线/嵌入向量）占 ≈10–20%，α+FiLM 调制占 ≈10%**。
   - "transformer"≠"全局注意力"：全分辨率全局注意力在 P3（1280 输入下 160×160）显存直接爆，且长程收益远小于局部对应与遮挡处理。
   - **嵌入向量（register）必须对标 GAP+MLP 基线**：它想干的"全局仲裁"，全局池化+小 MLP 十有八九也能干且便宜十倍；只有 E3（置零后输出变化）/E4（范数离群+低熵汇聚）/E5（迭代深度）三项明显赢过基线，才把预算给它。**占比 10–20% 是被测出来的上限，不是设计目标**。
8. **总线（L4）**：同一组每图动态 register 贯穿 P3→P4→P5；每尺度先从带模态/尺度嵌入的低分辨率 token 读取，再以小残差写回空间特征；前向结束立即清理，禁止跨图泄漏。

### Stage D/E｜Neck 与 Head

- Neck 11–22 官方预训练（通道不变 → 权重全继承）；Detect 回归分支原样，类别层适配 12 类（COCO 同名类迁移）。
- 辅助头（边界 BCE / 中心分类）仅当正则，λ 小 + 退火。

## 5. 评测与判定（修订）

### 5.0 优化目标：困难切片优先（v3）

选型与迭代的**第一目标**是困难切片（照度最低 20% / 拥挤最高 20% / 最小目标最多 20% / 模态质量最差 20%）
上的表现，平均分只作参考。理由：隐藏测试集难度递增，且难点切片才是分差所在。
→ 任何"平均分涨了但最坏切片掉了"的改动，视为**不合格**。

### 5.5 互补性定价（D1 必做，v3 新增）

**推理期模态屏蔽剖面**：拿同一个训练好的三模态模型，在推理时分别屏蔽 IR / Depth / RGB，
按条件切片测掉点：

| 观测 | 含义 | 行动 |
|---|---|---|
| 夜间切片屏蔽 IR 掉点 **≥ 3 分** | IR 是夜间主力 | IR 通路容量/交互按最高优先投入；对齐与蒸馏围绕它做 |
| 拥挤切片屏蔽 Depth 掉点 **≥ 2 分** | depth 承载遮挡/距离信息 | 深度表示、对齐、区域级交互全面投入 |
| 某模态在所有切片掉点 **< 0.5 分** | 该模态当前未被用上 | **不删除**（合规要求三模态被消费），但把容量优先给别的；同时排查是否被架构饿死（E3/E6） |

这套测量的价值：**零额外训练**就拿到"哪个模态在哪种条件下值多少分"，
比训 4 个单模态模型便宜得多，且直接回答"融合是不是真的在用"。

1. **判据唯一**：Test + 赛题口径 `conf=0.001 / iou=0.7 / max_det=100 / 无阈值`。
2. **条件分位切片**（照度最低 20%、拥挤最高 20%、最小目标最多 20%、模态质量最差 20%）→ 报**最坏切片**与衰减曲线。
3. **新增两项分解**：
   - **TIDE 式误差分解**（分类 / 定位 / 重复 / 背景 / 克隆）→ 决定投分辨率还是投分类平衡；
   - **尺度分桶 AP**（小/中/大）→ 直接对应分辨率/切片决策。
4. **cap 语义与配额策略**：
   - COCO 式 AP 是**类内排序** → **逐类单调校准对 AP 是恒等变换**，只通过"每图 ≤100 框的跨类截断"起作用；
   - 因此正确杠杆是 **跨类相对排序校准 + 逐类配额**（稀有类保底名额），且必须在**带 cap 的评测**下验证；
   - ⚠️ 需验证官方 scorer 是类内排序还是全局排序（若是全局排序，跨类校准价值大增）→ 用两次提交对照即可确认。
5. **短筛陷阱（重要）**：短跑 mAP 排序**不可靠**（我们实测过：中期 val 领先 +0.025，收敛后归零、Test 不迁移）。所以：
   - 结构类决策尽量用**机制指标**（E1–E7，便宜且稳定）；
   - 短筛只用于**一阶变量**（分辨率/规模），且必须同配方同种子；
   - 任何"融合 vs 不融合"的结论必须**全长训练 + 2 种子**。
6. **val ↔ Test 相关性验证**：早期提交 3–5 个 val 分数分散的配置，计算 rank 相关；确认 val 可预测后再用它迭代（否则只信 Test）。
7. **验证集设计**：分层留出 **400+ 张**用于迭代；最终 2–3 个候选用 2 种子（算力允许再加 3 折复核）。理由：209 张量级的 ±0.02 噪声会吃掉所有结论。
8. 逐类 AP 报表 + 混淆/漏检分析。

## 7. D0：数据审计 + 算力校准（数据到手当天）

**审计**
1. 条件轴：逐图照度、IR-RGB 相关、拥挤度（框数/最近邻框距/遮挡率）、尺度分布、清晰度。
2. **每图框数直方图 + >100 框比例**（决定配额策略）。
3. 类别分布 / 长尾 / 共现。
4. 模态质量：缺图率、depth 无效值拓扑、**残影双向边缘一致性**、depth 语义（米制/视差/归一化）。
5. 对齐：逐图偏移分布、峰宽/双峰、三对组合（RGB-IR / IR-D / RGB-D）→ **参数模型 + 缓存**。
6. 标注质检：可疑漏标 top-N 清单（人工复核）。
7. 产出：条件标签 + 400+ 分层留出集 + 最坏切片评测器 + TIDE/尺度分桶报表。

**算力校准（同一天，租的卡上做）**
8. 实测 **s/epoch**（2000 张 @960、batch 16、11s 与 11m、单流与三流）→ 填 §9 预算表 → 倒推"能做几次结论"。

## 9. 算力预算表（D0 实测后填实，先给公式）

```
单配置成本(小时) = s_per_epoch × epochs × 种子数 × 模态系数(三流≈2.0~2.5)
可用总量        = 租卡数 × 25 天 × 每天可用小时
配置预算        = 可用总量 / 单配置成本
```

| 量级（**占位估计，待 D0 实测校准**） | 值 |
|---|---|
| 11m @960 单流，300 轮 | 约 12–20 h |
| 三流，300 轮 | 约 25–45 h |
| 短筛 100 轮（三流） | 约 8–15 h |
| 4090 × 22 天满负荷 | ≈ 500 GPU·h |

**推论（排期必须遵守）**：全长 × 2 种子 × 三流 ≈ 50–90 h/配置 → 25 天里**全长只够 5–8 个配置**；因此 A/B 必须靠"短筛 + 机制指标"，全长只留给最终候选。

## 11. 明确不做

- ❌ Transformer 检测器作主干（2000 张 + 域宽 + 小目标三重不利）
- ❌ 多模型投票/集成提交（规则禁止）；EMA/SWA/TTA/蒸馏待合规确认
- ❌ 外部数据（含 VDT 进训练集）
- ❌ **用 VDT / 人为布景数据的结论给融合定价**（v3 修正：定价权归官方数据实测）
- ❌ **辅助模态用小容量随机初始化小流**（结构性压制，官方数据上直接丢分）
- ❌ 硬模态路由；❌ 强制三路等权的损失
- ❌ 像素级 depth 对齐幻想（残影）
- ❌ 把总线当地基；❌ 默认加 L_align/L_decorr
- ❌ 用 val 中期领先下结论；❌ 单种子定架构
- ❌ 零初始化恒等残差（会让支路饿死）
- ❌ 以"平均分"为唯一目标而牺牲困难切片

## 12. 风险登记册

| 风险 | 触发信号 | 止损 |
|---|---|---|
| 融合仍不承重 | E3 <1% | 回退最简强制调制 + 查 dropout 配方（**不因此判定融合无价值**） |
| 三份独立后段过参数化 | 档(a) 训练/验证 gap 大、输给(b)/(c) | 切到共享+适配器（**不是**退回小容量随机流） |
| 融合在某切片被压制 | §5.5 显示某模态掉点 < 0.5 分 | 排查架构是否饿死该路（E3/E6），按剖面重分配容量 |
| **交互白做**（花大参数没买到分） | E8 显示窗口注意力→L0 后困难切片掉点 < 1 分 | 退回 L0/L1，预算转分辨率/规模/蒸馏 |
| **总线白做** | 赢不过 GAP+MLP 基线（E3/E4/E5） | 用 GAP+MLP 做全局仲裁，删总线 |
| 对齐被残影污染 | 峰宽大/双峰、逐图方差大 | 全局先验收缩；只用低频 depth；可靠性掩码降权 |
| 融合整体不值（**仅当官方数据实测支持**） | 所有切片屏蔽任一模态掉点都 < 0.5 分，且三模态不敌 RGB-only | 转投分辨率/规模/蒸馏，保留合规三模态实现 |
| neck 统计过期 | 接入融合后精度骤降 | 融合输出改 BN / 做 BN 重校准 |
| 特征塌缩（过度对齐） | E2 私有分量≈0 | 加 L_decorr，降 λ_align |
| 域宽导致最坏切片崩 | 夜间/拥挤切片 AP 远低 | 提条件采样权重 + 连续谱退化增强 + copy-paste |
| cap 截断召回 | >100 框图比例高 | 跨类排序校准 + 逐类配额 |
| 算力不够 | 实测 s/epoch 超预期 | 分级降档：1280→960→768；或减种子 |
| 短筛排序骗人 | 短跑结论与全长不一致 | 结构决策改用机制指标，全长验证 |
