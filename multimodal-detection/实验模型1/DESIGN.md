# 实验模型1 —— 三模态融合方案（当前版）

> 赛题：面向城市场景的视觉多模态目标检测（RGB + Infrared + Depth，12 类，mAP@50-95）
> 本文档 = 当前方案的**状态 + 演进路线**，供逐步落地与技术报告引用。

---

## 0. 设计目标与约束

- **目标**：三模态互补——RGB 提供纹理/语义，IR（热）提供温差轮廓，Depth 提供几何前后关系；在夜间/逆光/遮挡/小目标下比单模态更稳。
- **约束**：2000 组小数据（防过拟合）、32G 单卡服务器、mAP@50-95（框精度敏感）、赛题允许 COCO 预训练、禁止简单模型集成（投票/平均）。
- **原则**：① 几何增强三模态**同步**（对齐不破坏）；② 每个模态**独立监督**（防止梯度被淹没/刻板印象）；③ 改动**可消融**（每步独立涨分）。

## 1. 当前已实现（代码现状）

### 1.1 三版本

| 版本 | 输入 | 融合 | 状态 |
|---|---|---|---|
| 基线模型1 | RGB 3ch | 无 | ✅ 官方 ultralytics 训练 |
| 基线模型2 | **5ch** RGB3+IR1+D1 | 前期融合（首层 3→5） | ✅ 自定义循环/多进程读图 |
| **实验模型1** | RGB3 + IR1 + D1 | **中间融合**（主流+辅助流，P3/P4/P5 分级） | ✅ 骨架 + 训练循环，待增强 |

### 1.2 实验模型1 当前架构

```
RGB(3) ──▶ 主流 backbone(yolo11s, COCO 预训练) ──▶ P3(512)/P4(512)/P5(1024)
                          (hook 索引 4/6/10，P5 取 C2PSA 后)
IR(1) ──▶ AuxStream(32,48,64) ──▶ f3'/f4'/f5'（H/8、H/16、H/32）
Depth(1)─▶ AuxStream(32,48,64) ──▶ f3''/f4''/f5''
                         │ concat(IR,D) 每尺度(64/96/128)
                         ▼
        ModalDropout（⚠️ 现为"每尺度整体置零"，待改为逐模态）
                         ▼
        FusionBlock(concat+1×1 压回主流通道) × P3/P4/P5
                         ▼
        SimplePAN(FPN+PAN) ──▶ Detect(12 类, 非端到端)
```

- 主流完整复用 `yolo11s.pt`（不改结构，只加融合点）；辅助流纯卷积轻量；训练用 `v8DetectionLoss`（已标量化）；EMA + 早停 + AMP；**DataLoader 多进程预取**（workers=4）。
- 数据管道：三模态一致性增强（flip/letterbox 同步、HSV 仅 RGB、Depth 最近邻）、Depth 固定对齐（-22px，可配）、路径配置化（`$MULTIMODAL_DATA_ROOT`/`--data-root`）。已完成 19 项审查修复与 VDT 接入（45 类对齐）。

## 2. 待落地增强（4 步路线）

### Step 1：Depth 三通道表征（信息层，改动小、收益直接）
- 输入 `1ch → [距离, 梯度(Sobel), 有效掩码]`：把"遮挡边界/无效区"显式喂给网络；
- 改动：`depth_mm_to_scaled` 增加 `rep="dist_grad_mask"`；`AuxStream` 首层 `Conv(1→3 in_ch)`；增强同步（几何三通道同参、噪声仅距离通道）；`PreprocessParams.depth_rep` 开关（默认 `dist` 不影响基线2）。

### Step 2：ModalDropout 改"逐模态独立"（鲁棒性，一行级改动）
- 现在：concat 后整体置零（只覆盖"齐全/全丢"两态）；
- 改为：在 concat **之前**分别对 `f_ir`、`f_dep` 独立置零（p=0.2）→ 覆盖"仅 IR 失效/仅 Depth 失效/双失效"，匹配赛题"**单**模态质量差不崩"。

### Step 3：辅助头 + 辅助损失（监督层，对"模态被用上"最关键）
- 融合**前**、每路（IR/Depth）各挂轻量 `AuxHead`（每尺度 cls+box）；
- 损失：`L_total = L_main + λ·(L_aux_ir + L_aux_dep)`，λ≈0.1~0.3、后期退火；
- 纪律：**梯度只回传辅助线**（不进主流 backbone，防污染预训练）；GT 复用主头分配；验收只看主头 mAP。

### Step 4：MEGA 多模态边缘引导注意力（表达层，最贵最后上）
- 结构：每个 P3/P4/P5 融合后，`F' = F_p + Σ_m w_m·(A_m ⊙ F_p)`，`A_m = σ(Conv1×1([F_p, E_m]))`；
- 边缘图 `E_m`：Depth 用 Step1 的梯度 ch1；RGB/IR 在模型内用**固定 Sobel 卷积**（零参数）从特征提取；
- `w_m` = 模态权重（与"空间门控"合并：**w 模态级 × A 位置级**——粒度正确，天然规避刻板印象/模态塌缩）；
- 可解释性：可输出 `A_rgb/A_ir/A_d` 热力图验证"各模态是否注意各自边缘"。

## 3. 后处理（现状与计划）

- **现状**：vendor 官方 `non_max_suppression`（conf=0.25, iou=0.7, max_det=300），按类、按置信度降序、IoU 抑制；赛题每图 ≤100 框按置信度截断（已实现）；这是标准单模型 NMS（非集成，允许）。
- **计划**：① `conf/iou` 提到入口可配；② 增加 `nms_mode="hard|soft"`（Soft-NMS 克服密集目标误杀）；③ val 上网格扫描最优参数（IoU×conf）。

## 6. 关键设计原则（写技术报告时引用）

1. **一致性增强**：几何（flip/crop/letterbox）三模态共享参数；颜色只 RGB；Depth 最近邻+无效填 0；
2. **对齐修正**：Depth 相对 RGB 固定右偏（实测中位 ~-22px@1920×1080），以 RGB 坐标系为基准、标签不动；
3. **防模态塌缩**：逐模态粒度（逐像素注意力 × 模态级权重）+ 独立辅助监督 + 逐模态 dropout + 门控含有效性掩码；
4. **小数据策略**：轻量辅助流（32/48/64）、注意力只放 P4/P5、λ 小且退火；
5. **可解释**：注意力热力图 + 门控分布检查（g 与"有效比例"相关=学可信度，常数=塌缩）。
