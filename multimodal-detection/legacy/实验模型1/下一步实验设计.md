# 下一步实验设计（Step5 候选）——— 基于 Step4b 的实测证据

> 写于 S4 训练进行中（ep70）。此时已确立的事实见下，所有建议都以这些**实测数字**为依据，
> 而不是猜测。数值口径：配对差分 = 同轮次 val mAP50-95 之差（S4 − S3），95% CI；
> Test 数字 = 赛题口径（conf=0.001 / iou=0.7 / max_det=100，VDT Test 1000 组）。

## 0. 已达成的实测结论（作为设计的输入）

| 结论 | 证据 |
|---|---|
| 多模态比纯 RGB 基线只高 +0.013~0.016 | Test：S3 0.5515/0.5543 vs 基线 0.5385 |
| 真边缘头（边缘 BCE 监督）**有收益** | val 配对 Δ = +0.0295 ± 0.0047（n=70，95% CI +0.020..+0.039） |
| 收益**不**来自"门控用边缘图" | 把边缘通道置零，特征只变 0.14~0.23%，Detect 输出只变 **0.03%**（`check_edge_effect.py`） |
| 收益更可能来自边缘损失对共享辅助流的塑造 | 同上；且 S4 的 γ 学到更大（P4：ep8 0.009 → ep60 0.063） |
| 融合强度是上限瓶颈 | `tanh(γ)` 全程 0.036~0.080（S3 终值），S4 ep60 = −0.053/+0.063/+0.006 |
| depth 近乎中性 | 同权重消融关 depth −0.013；注入 ±20px 深度错位 mAP 变化 <0.013 |
| IR 是真正在被用的辅助模态 | 同权重消融关 IR −0.050 |
| 赛题数据深度确有固定偏移 | 中位 −21.0 px@1920（IQR −27.2..−16.5），对齐后边缘相关 0.159→0.199 |

## 1. 方向 A：融合强度结构性升级（优先级最高）

**动机**：`tanh(γ) ≈ 0.05` 意味着融合支路只能改动主干特征 5%，与"IR 消融掉 0.05、
depth 消融掉 0.013"完全一致 —— 辅助模态有信息量，但**通路太窄**。

| 编号 | 改动 | 位置 | 预期 |
|---|---|---|---|
| A1 | `proj` 输出先做尺度归一（BN 或 `p·sqrt(C)/‖p‖`），再加残差 | `FusionInjector.hook` | 让 γ 的语义变成"相对幅度"而不是"绝对尺度"，学到的 γ 有用武之地 |
| A2 | γ 去饱和：`γ_eff = γ_max·tanh(γ/γ_max)`（γ_max≈0.3），或直接线性 + clip | `FusionInjector` | 允许融合强度超过 8% 天花板 |
| A3 | γ 下限/课程：前 N 轮把 γ 提到 floor（如 0.15）再放开 | `train_loop.train_custom`（已有 fusion warmup 钩子） | 强制早期就利用辅助信息，避免退化到"忽略辅助"的局部最优 |
| A4 | 逐通道门控（gate 输出 C 通道而非 1 通道） | `FusionInjector.gate` | 允许按通道选择性融合 |
| A5 | 模态竞争：对模态做 softmax 归一化而不是各自独立门控 | `FusionInjector` | 避免两模态同时放大导致的主干被淹没 |

**必须保持**：`γ=0/α=0` 时与官方 YOLO11s 逐位等价（`model_builder.__main__` 自检有断言）。

**建议的第一刀**：只做 A1+A2，且**只对 IR 生效**（depth 先按方向 B 处理或暂时冻结），
这样能干净地回答"拉宽融合通路是否直接涨点"。

## 2. 方向 B：depth 表示改造（优先级中）

| 编号 | 改动 | 预期 |
|---|---|---|
| B1 | 用**相对深度**（每图 min-max 或中位归一）替代绝对 mm/20000 | 消除场景尺度差异，让 depth 的统计分布稳定 |
| B2 | 无效值语义显式化（0 = 无效已有掩码，但补充"近处缺失"的语义） | 减少噪声注入 |
| B3 | depth 的梯度/边缘作为额外通道（而不是让门控用固定 Sobel） | 与已验证有效的"边缘监督"思路一致 |
| B4 | 反投影 3 通道 (x,y,z) | 信息量最大但改动最大，最后考虑 |

**注意**：若 B 做完 depth 消融仍 ≈ 0，则结论应是"本数据集 depth 无额外信息"，
把它降级为"赛题要求保留的输入通道"，不再投入训练预算。

## 3. 方向 C：复现与统计（必须在 A 之前做）

**动机**：S4 的收益是单次 run 配对结果；`EdgeHead` 的初始化消耗 RNG，使后续随机初始化的
类别输出层与 S3 不同源，因此**不能排除训练轨迹随机性**。

- **C1 第二种子复现**：`--seed 43` 重跑 S3(无边缘头) 与 S4(有边缘头)，同轮次配对；
  两次 run × 120 轮 ≈ 5 小时（功耗正常时约 75 s/轮）。
  判据同预注册口径：Δ 的 95% CI 下界 > 0 才算复现成功。
- **C2 Test 复测**：训练结束后用 `eval_test.py --exp1 <多个> --struct "mega=false"` 一次跑完
  （已在 `814c961` 支持多 checkpoint 同管线对比）。

## 4. 建议顺序（假设功耗限制已解除，约 75 s/轮）

1. **C1 第二种子复现**（≈5 h）——决定"边缘 BCE 收益"是否可信；
2. 若复现成立 → **A1+A2（IR-only）** 单次 run（≈2.5 h），与 S4 同轮次配对；
3. 若 A 有效 → 再考虑 A3/A4/A5 与 B 的组合；
4. 全流程都用同一套脚本产出证据：`check_fusion.py`（γ）、`check_edge_effect.py`（推理影响力）、
   `check_augment.py` / `check_align.py` / `check_depth_sensitivity.py`（数据管线）。

## 5. 不要做的事（已被数据否定）

- ❌ 继续加"辅助头"数量而不动融合强度：门控输入层面的改动在推理时影响 <0.1%（已实测）；
- ❌ 把 depth 边缘梯度当监督目标（depth 是模型输入，等于抄任务，距离头已踩过这个坑）；
- ❌ 用 conf=0.25 评测报数（会低估约 30%）；
- ❌ 用同权重消融之外的口径横比不同 run（val 划分不同不可比，只有 Test 1000 组可比）。
