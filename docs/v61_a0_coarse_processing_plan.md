# V6.1 IR A0 粗处理方案

日期：2026-09-26

## 处理顺序

原始 RGB/IR -> 原位幻影拟合与去除 -> 矩形交集黑框检测 -> 清洁 IR 与精简质量信息 -> 分类型仿射候选 -> 方向投影和区域验证 -> 输出最终 A0。

## 1. 幻影处理

- 将幻影建模为 RGB 在 IR 原位的光学投影，允许通道混合、强度衰减和轻微模糊。
- 比较零位移拟合和错位对照拟合，只有零位移拟合显著更好时才去除。
- 输出幻影概率和样本级置信度；低置信度严格保持原始 IR。
- 幻影是光学污染目标，不作为 RGB/IR 几何配准目标。

## 2. 黑框处理

- 黑框检测只运行一次，并且必须在去幻影之后运行。
- 有效区域建模为图像画布矩形与旋转传感器矩形的交集。
- 从边界连通暗区获得初始有效区域，拟合旋转矩形，再与画布求交。
- 删除有效面积比、外部占比、多边形面积、边数和固定边长等旧接受门槛。
- 仅保留外部显著更暗、边界可由矩形直线解释以及失败时全有效回退。
- 只记录 black_border_area_px 和源图尺寸，不把面积作为接受条件或质量通道。
- 计算边缘前平滑填充黑框外部，并通过有效 mask 排除，避免黑框直线成为物体边缘。

## 3. 质量合同

空间图只保留 ghost_probability、black_invalid_mask、geometry_mask 和 thermal_confidence。

元数据保留 sampling_matrix、affine_physical、ghost_confidence、alignment_confidence、selected_mode、black_border_area_px、source_shape 和 a0_version。

coarse_available 使用样本级标量，不扩展为常数图。RGB/IR 边缘及差值在运行时生成。

## 4. 仿射候选

- Identity 指已经去幻影和黑框影响、但尚未执行仿射变换的 IR。
- 候选顺序：Identity、旧 A0、仅平移、旋转加平移、完整相似变换、Identity 大角度救援。
- 旋转搜索限制为正负 25 度，缩放约 0.80 到 1.25。
- 先估计旋转和缩放，再估计平移。
- 复杂候选与简单候选效果接近时选择简单候选。

## 5. 方向投影与验证

- 在共同有效区域计算 0、90、45、135 度边缘投影。
- 方向投影作为旋转和缩放候选的必要验证票，不单独决定结果。
- 同时要求二维边缘改善、多个分散区域改善、留出区域改善和前景不得恶化。

## 6. 训练与尺寸兼容

- Stage A 输入去幻影后的清洁 IR，不再人为加入幻影。
- 所有坐标和阈值基于运行时 H/W，支持数据集中的两种尺寸。
- mask 使用最近邻缩放，连续图使用双线性或面积缩放，sampling matrix 经过对应 letterbox 变换。
- 无幻影时回退原图；无黑框时回退全有效 mask；几何支持不足时回退 Identity 或 A0，禁止产生全零图像。
